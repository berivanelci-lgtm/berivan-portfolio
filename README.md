# Berivan's Little Digital Garden ✿

Kediye tıklayarak açılan karşılama ekranına, Türkçe/İngilizce dil değiştirmeye, koyu temaya ve pastel teknoloji çizimlerine sahip kişisel portfolyo.

## Dosyalar
- `index.html`: içerik ve sayfa yapısı
- `style.css`: renkler, çizimler, düzen ve mobil görünüm
- `script.js`: kediyle giriş, dil değiştirme, tema ve menü etkileşimleri

## Yerel açılış
Dosyaları aynı klasörde tutup `index.html` dosyasını tarayıcıda aç. İstersen VS Code Live Server kullan.

## GitHub Pages
1. GitHub'da `berivan-portfolio` adında public repository oluştur.
2. Bu klasördeki dört dosyayı repository'nin ana dizinine yükle.
3. Settings → Pages → Deploy from a branch seç.
4. Branch `main`, folder `/(root)` seçip Save'e bas.
5. Birkaç dakika sonra Pages sayfasında çıkan adresi aç.
